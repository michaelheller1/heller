# סוכן "מותג הסיעוד": מדריך הקמה

סוכן למחקר על שיווק, טיפוח ושימור לקוחות לחברת סיעוד בבית, ולהפקת המלצות ותוצרים.

## מבנה הקבצים

```text
agent/
├── README.md                     # המדריך הזה
├── system_prompt.md              # הוראות הסוכן (להדבקה)
└── knowledge/
    ├── 01_company_profile.md     # פרופיל החברה
    ├── 02_research_protocol.md   # איך חוקרים מתחרים
    ├── 03_family_journey.md      # מסע המשפחה והצרכים
    ├── 04_service_quality.md     # מדידה ושיפור של איכות השירות
    ├── 05_output_templates.md    # תבניות התוצרים
    └── 06_compliance.md          # ציות, הסכמות ופרטיות
```

## שלב א': הקמה ב־Claude (בלי קוד)

1. נכנסים ל־claude.ai, בוחרים **Projects** ואז **Create project**, ונותנים לפרויקט את השם "מותג הסיעוד".
2. ב־**Project instructions** מדביקים את כל התוכן של `system_prompt.md`.
3. ב־**Project knowledge** מעלים את 6 הקבצים מתיקיית `knowledge/`.
4. מוודאים ש**חיפוש באינטרנט** (Web search) מופעל בהגדרות.
5. אפשר לבחור את המצב **Research** לחקירות מעמיקות.

## השיחות הראשונות המומלצות (לפי הסדר)

1. "בצע סקירת בסיס על מטב לפי פרוטוקול המחקר, והפק דוח מתחרים." אחר כך חוזרים על זה לדנאל, עמל ותגבור, כל חברה בשיחה נפרדת.
2. "סקור את Home Instead, Visiting Angels ו־Right at Home, עם דגש על תוכן לבני משפחה, ניוזלטר ושימור לקוחות."
3. "חפש מודלים מוכחים מחוץ לארה"ב (בריטניה, הולנד, אוסטרליה) לשימור לקוחות ולמדידת שירות בטיפול בבית."
4. "הפק סיכום השוואתי ו־10 המלצות לפי סדר העדיפויות."
5. "בנה תוכנית מדידת שירות לרכזות ולסניפים, ומנגנון לאיסוף הסכמות."
6. "הפק לוח תוכן לחודש הראשון, מאגר הודעות, דף למאתרות ותוכנית חבר מביא חבר."

עדיף להתחיל כל משימה גדולה בשיחה חדשה בתוך הפרויקט. תוצרים טובים כדאי לשמור כקובץ ידע נוסף בפרויקט, כדי שהסוכן ייבנה עליהם.

## שלב ב': אוטומציה
- סריקת מתחרים חודשית שרצה כמשימה מתוזמנת ושולחת דוח "מה השתנה".

## שלב ג': חיבור למערכות
- סוכן שנבנה עם Claude Agent SDK, מחובר ל־CRM (אחרי הסדרת הפרטיות): התראות על סימני נטישה, סקרים אוטומטיים ודוח מדדים לכל סניף.

## שאלות פתוחות (לעדכן את `01_company_profile.md` אחרי שמתקבלות תשובות)

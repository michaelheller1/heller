# המדריך המלא לשיווק ולמכירות באינסטגרם

מדריך בעברית, מרמת מתחילים ועד רמת מומחה, עם דגש על תחום התזונה ואורח החיים הבריא ועל השוק הישראלי.

- **המסמך המוכן:** `Instagram_Marketing_Guide_HE.docx`
- **התוכן:** קובצי הטקסט בתיקייה `content/` (פרק לכל חלק)
- **בנייה מחדש** אחרי עריכת התוכן (נדרשים Node.js עם החבילה `docx`, Python 3, LibreOffice ו-Poppler):

```bash
./make.sh
```

הסקריפט בונה את המסמך פעמיים: בפעם הראשונה כדי לחשב את מספרי העמודים בתוכן העניינים, ובפעם השנייה עם המספרים הסופיים.
